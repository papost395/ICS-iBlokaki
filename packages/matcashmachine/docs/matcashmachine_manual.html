Ιεραρχία Exceptions
Πέντε τύποι σφαλμάτων — πιάσε αυτό που χρειάζεσαι
MatConnectionException
Socket δεν συνδέθηκε ή έπεσε κατά τη διάρκεια επικοινωνίας. Δεν κάνει retry — διαδίδεται αμέσως.
MatCommunicationException
Ταμειακή επέστρεψε NAK ή δεν έκανε ACK στο handshake. Προκαλεί retry.
MatEcrErrorException
Η ταμειακή επέστρεψε κωδικό σφάλματος (π.χ. '06'=κλειστή απόδειξη). Περιέχει errorCode και command.
MatPacketException
Λάθος checksum ή κακή μορφή πακέτου. Στέλνει NAK στην ταμειακή και κάνει retry.
MatTimeoutException
Η ταμειακή δεν απάντησε εντός 10s (default). Προκαλεί retry με 800ms backoff.
MatException (βάση)
Κοινή βάση όλων. Πιάσε μόνο αυτό αν θες να χειριστείς ΟΛΑ τα σφάλματα με ένα catch.
Dart
try { await mat.itemSale(2.50, description: 'ΚΑΦΕΣ', department: 1); await mat.sendPayment(2.50, paymentCode: 1); } on MatEcrErrorException catch (e) { // Η ταμειακή είπε "όχι" — κωδικός e.errorCode, εντολή e.command print('ECR Error ${e.errorCode}: ${e.message}'); } on MatTimeoutException catch (e) { print('Timeout: $e'); // Ελέγξε το δίκτυο } on MatConnectionException catch (e) { print('Σύνδεση χαμένη: $e'); // Reconnect }

Ελληνικοί Χαρακτήρες — Windows-1253 (CP1253)
Πλήρης υποστήριξη Ελληνικών στις περιγραφές ειδών, κεφαλίδες, μηνύματα

🇬🇷 Υποστηριζόμενοι Χαρακτήρες

  • Κεφαλαία με τόνο: Ά Έ Ή Ί Ό Ύ Ώ
  • Μικρά με τόνο: ά έ ή ί ό ύ ώ
  • Όλο το ελληνικό αλφάβητο Α-Ω, α-ω
  • Ευρώ: € (byte 0x80)
  • Διαλυτικά: Ϊ Ϋ ΐ ΰ ϊ ϋ

⚠️ Δεν Υποστηρίζεται

  • Unicode εκτός Windows-1253 (π.χ. Κινεζικά)
  • Emoji 😀 (μη encodable)
  • Ειδικά σύμβολα εκτός πίνακα
  • UTF-8 multi-byte sequences
  • Αν σταλεί μη-encodable → MatPacketException
Dart
// Ορισμός κεφαλίδας απόδειξης στα Ελληνικά await mat.programHeader([ 'ΚΑΦΕΤΕΡΙΑ ΑΚΡΟΠΟΛΗ', 'ΑΦΜ: 123456789 — ΔΟΥ Αθηνών', 'Τηλ: 210-1234567', ]); // Πώληση είδους στα Ελληνικά — δουλεύει αυτόματα! await mat.itemSale(2.50, description: 'ΚΑΦΕΣ ESPRESSO', department: 1); // Για ASCII-only ταμειακές (μη-ελληνικές) final mat = MatProtocol(host: '192.168.1.100', port: 9100, charset: MatCharset.ascii);

Ημερήσιο Κλείσιμο — Z-Report
Έκδοση αναφοράς ημερήσιου κλεισίματος με επαλήθευση κατάστασης
⚠️
Προϋπόθεση: Πριν το Z-report, βεβαιωθείτε ότι δεν υπάρχει ανοιχτή απόδειξη (fiscalStatus.transactionOpen == false) και ότι η ημέρα είναι ανοιχτή (fiscalStatus.dayIsOpen == true).
Dart
/// Ημερήσιο κλείσιμο με έλεγχο κατάστασης πριν Future<void> doZReport(MatProtocol mat) async { // 1. Έλεγχος κατάστασης πριν το Z final MatStatus status = await mat.getStatus(); if (status.fiscalStatus.transactionOpen) { throw StateError('Υπάρχει ανοιχτή απόδειξη! Κλείσε την πρώτα.'); } if (!status.fiscalStatus.dayIsOpen) { throw StateError('Η ημέρα είναι ήδη κλειστή (Z ήδη εκδόθηκε).'); } // 2. Προαιρετικά: X-report πρώτα (διαβάζει σύνολα χωρίς μηδενισμό) await mat.executeIssueReport(1); // type=1 → X-report // 3. Z-report (ημερήσιο κλείσιμο — αυξάνει Z-counter) // Δώσε μεγαλύτερο timeout — η εκτύπωση παίρνει χρόνο await mat.sendRawCommand( MatPacket(requestCode: 'x', fields: ['7']), // type=7 → Z-report replyTimeout: const Duration(seconds: 60), ); print('✅ Z-Report εκδόθηκε επιτυχώς!'); }

Πλήρης Ροή Εργασίας Ημέρας
Από αρχή ημέρας έως ημερήσιο κλείσιμο
Dart
final mat = MatProtocol(host: '192.168.1.50', port: 9100); try { // ── ΕΝΑΡΞΗ ΗΜΕΡΑΣ ────────────────────────────── await mat.connect(); final s = await mat.getStatus(); print('Ημέρα ανοιχτή: ${s.fiscalStatus.dayIsOpen}'); // Δεν χρειάζεται να "ανοίξεις" ημέρα — ανοίγει αυτόματα με την πρώτη απόδειξη! // ── ΕΙΣΑΓΩΓΗ ΜΕΤΡΗΤΩΝ (Cash-In) ──────────────── await mat.openCashInOut(1, 0); // type=1 cash-in // ... πληκτρολόγηση ποσού στην ταμειακή ... // ── ΠΩΛΗΣΗ #1 (Αρχικό δώρο) ──────────────────── await mat.setActiveClerkCommand(1); await mat.itemSale(5.00, description: 'ΓΛΥΚΟ ΗΜΕΡΑΣ', department: 3); await mat.sendPayment(5.00); // Μετρητά by default // ── ΤΕΛΟΣ ΗΜΕΡΑΣ: X-report, μετά Z ───────────── await mat.executeIssueReport(1); // X-report await mat.sendRawCommand(MatPacket(requestCode: 'x', fields: ['7']), replyTimeout: const Duration(seconds: 60)); // Z-report } on MatException catch (e) { print('❌ Σφάλμα: $e'); } finally { await mat.disconnect(); await mat.dispose(); // ΠΑΝΤΑ σε finally! }
💡
Best Practice: Βάλε πάντα disconnect() και dispose() μέσα σε finally block ώστε οι πόροι να αποδεσμεύονται ακόμα και σε περίπτωση exception.
